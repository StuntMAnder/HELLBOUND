# HELLBOUND — publish and play

## Publish the website with GitHub Pages

1. Open the repository: https://github.com/StuntMAnder/HELLBOUND
2. Select **Settings**.
3. In the left sidebar, open **Pages** (under **Code and automation**).
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Set **Branch** to `main`.
6. Set the folder to `/(root)`.
7. Click **Save**.
8. Wait for GitHub Pages to finish deploying. This can take several minutes.
9. Return to the Pages settings and click **Visit site** when the link appears.

The expected project-site address is:
https://stuntmander.github.io/HELLBOUND/

## Play

- Open the published site in a modern browser.
- Player 1: A/D to move, W to jump, F/G/H for attacks, T to guard.
- Player 2: Left/Right to move, Up to jump, J/K/L for attacks, I to guard.
- Enter advances screens and confirms selections. Escape returns to fighter select.
- The Reset button returns to fighter select.

## Browser note

The game is a static HTML page that uses JavaScript for its interactive parts. A normal browser runs that JavaScript automatically; no separate JavaScript installation is needed. If a school-managed browser or device blocks JavaScript, GitHub Pages cannot override that restriction. Use a device/browser where scripts are permitted, or ask the device administrator.

## Privacy

GitHub Pages websites are publicly viewable. Do not put passwords, private information, or personal files in this repository.
